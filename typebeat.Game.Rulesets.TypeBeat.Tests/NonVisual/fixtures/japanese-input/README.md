Mozc romaji regression fixture

Snapshot of [Google Mozc’s romaji input table](https://raw.githubusercontent.com/google/mozc/60af02ff797275f2ba1b7fddccdec916798d112e/src/data/preedit/romanji-hiragana.tsv). Revision: `60af02ff797275f2ba1b7fddccdec916798d112e`. Its licence is retained in `LICENSE.mozc`.

Tests cover every kana-producing entry, including carried consonants after small tsu. Punctuation and literal Latin shortcuts are outside this kana input fixture. The game’s additional spelling and pronunciation aliases remain separate.
