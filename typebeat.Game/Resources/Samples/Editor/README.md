# Editor metronome samples

Unmodified classic osu! editor samples from `osu!ui.dll`, downloaded from the official stable update service:

- Update manifest: https://osu.ppy.sh/web/check-updates.php?action=check&stream=stable40
- Resource assembly: https://m3.ppy.sh/r/osu!ui.dll/f_6448b4b0a3ec3a875f850a502fd29213
- Original resources: `osu_ui.ResourcesStore.resources`, byte arrays `metronomehigh` and `metronomelow`.

`metronomehigh.wav` accents the beginning of a bar; `metronomelow.wav` sounds on the other beats. Both play at their original pitch. The samples are scoped to the editor BPM metronome; lyric timing ticks retain their existing sounds.
